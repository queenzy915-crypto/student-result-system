# Student Result Management System

A Python program that manages student records and results.
Built for the New Horizon Python Programming Project.

Author: Kenneth-Okoyegbe Chiziterem (Matric No: 24/sci01/110)

## Features
- Add, view, search, update and delete students
- Record and update scores for at least 5 subjects
- Calculate total, average and grade (A-F)
- Student report card
- List students with results, sorted by average or name
- Class statistics (highest, lowest, average)
- Save a text report to a file
- Data saved to data/students.json and loaded on startup

## How to run
1. Install Python 3.
2. Open a terminal in the project folder.
3. Run: python main.py
4. Choose an option from the menu.

## Files
- main.py: menu and program flow
- student.py: Student class
- results.py: total, average and grading
- storage.py: save and load JSON data
- reports.py: reports and statistics
- data/students.json: saved data

## Python concepts used
Variables and type conversion, if/elif/else, for and while loops,
lists, dictionaries, functions, sorting, try/except/else,
file handling (JSON), modules, classes (OOP), dates and times
(datetime), regular expressions (re), and the standard library (os, json).
